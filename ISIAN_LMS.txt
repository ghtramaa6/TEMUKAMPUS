HALAMAN WIREFRAME TUGAS 1 YANG DIIMPLEMENTASIKAN:
Buat Laporan — halaman desktop TemuKampus untuk melaporkan barang hilang atau barang temuan di lingkungan kampus.

KOMPONEN 1
Nama komponen: Sidebar Navigasi
Lokasi di kode: index.html #sidebar, #primary-nav; styles.css .sidebar; script.js toggleMenu()
Perilaku & keputusan desain: Sidebar menampilkan menu utama secara konsisten. Pada layar kecil, tombol hamburger membuka dan menutup menu agar area formulir tetap luas dan mudah diakses.

KOMPONEN 2
Nama komponen: Header dan Pencarian Cepat
Lokasi di kode: index.html .topbar, #quick-search; styles.css .topbar; script.js event submit #quick-search
Perilaku & keputusan desain: Header menampilkan posisi pengguna dalam aplikasi dan kolom pencarian. Saat dicoba, pencarian memberi pemberitahuan jujur bahwa halaman pencarian belum diimplementasikan.

KOMPONEN 3
Nama komponen: Pilihan Jenis Laporan
Lokasi di kode: index.html #report-kind, input[name="reportType"]; script.js setReportType()
Perilaku & keputusan desain: Pengguna memilih barang hilang atau temuan menggunakan radio button. Pilihan aktif diberi penanda warna dan teks lokasi menyesuaikan jenis laporan agar input tidak membingungkan.

KOMPONEN 4
Nama komponen: Formulir Data Barang
Lokasi di kode: index.html #report-form, #item-name, #category, #location, #event-date, #description; script.js validateField(), submitReport()
Perilaku & keputusan desain: Form mewajibkan nama, kategori, lokasi, tanggal dan deskripsi umum. JavaScript memvalidasi kelengkapan, panjang deskripsi, tanggal, dan beberapa pola informasi sensitif sebelum simulasi dikirim.

KOMPONEN 5
Nama komponen: Unggah Foto dan Pratinjau
Lokasi di kode: index.html #image-upload, #item-photo, #file-preview; script.js validatePhoto(), clearPhoto()
Perilaku & keputusan desain: Pengguna dapat memilih foto PNG/JPG/WebP maksimal 3 MB, melihat pratinjau, atau menghapus foto. Pembatasan ukuran dan jenis file membantu mencegah input tidak sesuai kebutuhan.

CATATAN PENGERJAAN
Tantangan terbesar dan bagaimana kamu menyelesaikannya:
Tantangan utama adalah menerjemahkan desain wireframe desktop menjadi tampilan web yang responsif sekaligus menjaga privasi informasi barang. Solusinya menggunakan HTML semantik, CSS Grid/Flexbox dengan custom property untuk konsistensi, serta JavaScript terpisah untuk validasi, unggah foto, dan pesan kesalahan. Deskripsi publik diperiksa terhadap beberapa pola data pribadi, sementara konfirmasi dibuat sebagai simulasi tanpa menyimpan data di server. Interaksi menu pada layar kecil dan pesan validasi juga disediakan agar pengguna mendapat umpan balik yang jelas.
